# Stone Paper Scissor Game

A fun and interactive **Stone Paper Scissor** game built using **HTML, CSS, and JavaScript**. In this game, the player competes against the computer by choosing Stone, Paper, or Scissor. The computer generates a random choice, and the game instantly displays the result while keeping track of the score.

This project was created to strengthen my understanding of **JavaScript fundamentals, DOM manipulation, event handling, and responsive web design**.

---

## Features

- Play against the computer
- Random computer choice generation
- Instant game result (Win, Lose, or Draw)
- Live score tracking
- Clean and responsive user interface
- Works smoothly on desktop and mobile devices

---

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Game logic and interactivity

---

## How to Play

1. Choose **Stone**, **Paper**, or **Scissor**.
2. The computer randomly selects its choice.
3. The game compares both choices and displays the result.
4. Your score updates automatically after each round.
5. Continue playing as many rounds as you like.
